Codocs reaches 1.0.0. The MCP package `co-documentation` and the VS Code extension `seojaewan.codocs` are released as their first stable version, including project-root-relative paths for `codocs_write` and `codocs_validate` and support for `.codocs` folders inside project subfolders.

Codocs가 1.0.0이 된다. MCP 패키지 `co-documentation`과 VS Code 확장 `seojaewan.codocs`를 첫 안정 버전으로 배포하며, `codocs_write`·`codocs_validate`의 프로젝트 루트 기준 경로와 프로젝트 하위 폴더의 `.codocs` 지원을 포함한다.
