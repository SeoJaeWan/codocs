Document paths now behave the same on every OS. On Windows, paths shown in hover tooltips, "Open source" labels, rename lists and MCP tool results, and the order of document lists, are the same as on macOS: paths always use `/`, and `\` is accepted as a separator only in Windows path input.

문서 경로가 모든 OS에서 같게 동작한다. Windows에서도 Hover 툴팁, 원문 열기 라벨, 이름 바꾸기 목록, MCP 도구 결과에 보이는 경로와 문서 목록의 순서가 macOS와 같아진다. 경로는 항상 `/`를 쓰며, `\`는 Windows 경로 입력에서만 구분자로 인정한다.
