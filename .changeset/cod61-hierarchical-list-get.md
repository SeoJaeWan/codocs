Change `codocs_list` and `codocs_get` to follow the document hierarchy and read by name. `codocs_list` now takes an optional `parent` (a document name) instead of filters and a cursor: without it, it returns root documents (those with no `_codocs.parent`); with it, it returns that document's direct children. Each item carries `sections` (section names in document order, no content) and `childCount`, results are not paginated, and a `cursor` input or any unknown property is `invalid_input`. The root result also returns `unreachable`: documents that root traversal cannot reach because their parent names no document, they belong to a parent cycle, or their parent value is malformed. A `parent` that names no document is `not_found`. `codocs_get` now takes `addresses` (1 to 20 strings) instead of `ids`: `name` reads a document and `name:section` reads one top-level section, with a per-address result in request order; a missing section is the new `section_not_found` code, and a malformed address fails only its own result. A section result has `section`, the whole-file `revision` and the references made inside that section. `references` and `referencedBy` now list document names instead of IDs. `codocs_write` and `codocs_rename` still take an `id`.

`codocs_list`와 `codocs_get`이 문서 계층을 따라 탐색하고 이름으로 읽도록 바뀐다. `codocs_list`는 필터와 cursor 대신 선택 입력 `parent`(문서 이름)를 받는다. 생략하면 `_codocs.parent`가 없는 최상위 문서를, 주면 그 문서의 직속 자식을 돌려준다. 항목마다 `sections`(문서에 적은 순서의 섹션 이름, 내용 없음)와 `childCount`를 담고, 결과를 페이지로 나누지 않으며, `cursor` 입력이나 알 수 없는 속성은 `invalid_input`이다. 최상위 결과에는 `unreachable`도 담는다. parent에 적은 이름의 문서가 없거나, parent 순환에 속하거나, parent 값이 올바르지 않아 최상위에서 닿을 수 없는 문서다. 문서가 없는 `parent`는 `not_found`다. `codocs_get`은 `ids` 대신 `addresses`(문자열 1~20개)를 받는다. `이름`은 문서를, `이름:섹션`은 최상위 섹션 하나를 읽으며 주소마다 요청 순서대로 결과를 돌려준다. 없는 섹션은 새 코드 `section_not_found`이고 잘못된 주소는 그 결과만 실패한다. 섹션 결과에는 `section`, 파일 전체의 `revision`, 그 섹션 안에서 건 참조가 담긴다. `references`·`referencedBy`는 ID 대신 문서 이름을 담는다. `codocs_write`와 `codocs_rename`은 계속 `id`를 받는다.
